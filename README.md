# SlicePilot
SlicePilot — AI Pizza Delivery for Kent Pizzeria (fictional demo restaurant, 112 Ashley Street, Hartford, CT). AI-powered pizza ordering and delivery: website, Retell AI calling agent, Claude chatbot, Stripe Payment Links, DoorDash Drive / Uber Direct delivery.

> **Note:** This is a demo/practice project. Kent Pizzeria is a fictional restaurant — no real orders, payments, or deliveries.
